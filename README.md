# HTTP-анализ и отладка запросов с Fiddler

Учебный QA-проект: изучаю, как приложения общаются с сервером по HTTP, и учусь
перехватывать, анализировать и изменять запросы с помощью **Fiddler**.

**Статус:** в процессе (добавляю по одному сценарию)

## Цель проекта
- Научиться читать HTTP-запросы и ответы: метод, заголовки, тело, код, время.
- Освоить инструменты Fiddler: Inspectors, Composer, Breakpoints, AutoResponder, Filters.
- Оформить результаты как тестовые сценарии с шагами, ожидаемым и фактическим результатом.

## Объект тестирования
Открытые учебные API, для которых не нужна регистрация и ключи:
- [JSONPlaceholder](https://jsonplaceholder.typicode.com) — посты, комментарии, пользователи (CRUD-запросы).

## Инструменты
- Fiddler (перехват и изменение трафика)
- Браузер (для отправки запросов и просмотра ответов)

## Структура репозитория
```
fiddler-http-testing/
├── README.md        описание проекта
├── scenarios/       сценарии: шаги, ожидаемый и фактический результат
├── screenshots/     скриншоты из Fiddler
├── findings.md      выводы
└── .gitignore       исключает файлы сессий Fiddler (в них могут быть секреты)
```

## Сценарии
| № | Сценарий | Инструмент Fiddler | Статус |
|---|----------|--------------------|--------|
| 01 | GET: получить пост и разобрать запрос/ответ | Inspectors | Выполнен |
| 02 | POST: создать пост через Composer | Composer | В работе |
| 03 | Изменить запрос на лету (неверный ID) | Breakpoints | Запланирован |
| 04 | Подмена ответа сервера (500, пустой список) | AutoResponder | Запланирован |
| 05 | Анализ времени ответа | Statistics / Timeline | Запланирован |

## Как воспроизвести
1. Установить и запустить Fiddler.
2. Открыть в браузере `https://jsonplaceholder.typicode.com/posts/1`.
3. Найти запрос в списке сессий Fiddler и открыть вкладку Inspectors.
4. Дальше следовать шагам из нужного файла в папке `scenarios/`.

## Безопасность
Файлы сессий Fiddler (`.saz`) и HAR-файлы не публикуются: в них могут быть
заголовки авторизации и cookies. Скриншоты проверяются перед загрузкой.
